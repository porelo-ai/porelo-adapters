# Adapter review conversion

This unpublished module holds what the forge adapters share of a review: a forge's line comment written as a result
of Porelo's review profile 2, the profile's pages and cursors, a submission's one result read as a reply or a comment
on lines, and the text rules both directions follow. It knows no forge and depends on no forge client; each adapter
maps its own client's records onto it, as the [adapter documentation](../../doc/index.md) describes.
