# Porelo Adapters

<img src="doc/images/crazy-chicken.svg" width="350" alt="Crazy chicken - just hatched">

> **Crazy chicken - just hatched.** Interfaces, formats and even the purpose may change any day. Use it only to try
> ideas, never to build on.


Porelo Adapters provides build adapters and the shared [contract suite](contract/README.md) that tests them through `org.fuin.porelo.Build2`.
The [adapters](adapters/README.md) group holds the GitHub and Forgejo executables; adapters depend only on `porelo-build-api` and `porelo-wire` from Porelo and receive the forge token in each call.
See the [documentation](doc/index.md), [contributing guide](CONTRIBUTING.md), and [security policy](SECURITY.md).
